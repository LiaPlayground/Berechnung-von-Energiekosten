# 2. Berechnung von Energiekosten

Im Alltag sprechen alle von „Stromverbrauch“, was physikalisch gesehen aber nicht richtig ist. Energie wird nicht verbraucht, denn das würde ja heißen, sie existiert dann nicht mehr. Leider hat sich der falsche Begriff „Stromverbrauch“ eingebürgert. 

Der Energieerhaltungssatz gilt weiterhin: Energie wird nicht verbraucht, sondern in andere Formen umgewandelt (manchmal auch unerwünscht) und zwischen Körpern übertragen. Sieh dir dies im Folgenden zunächst an!

## 2.2 Rechnung für die elektrische Energie

    --{{0}}--
Der Zählerstand wird am besten zum Jahresende an den Energieversorger geschickt. So kann dieser ausrechnen, wie viel man bezahlen muss. Er schätzt auch gleich, wie viel man im nächsten Jahr vermutlich brauchen wird. So kannst du monatlich einen festen Betrag (den „Abschlag“) bezahlen und am Ende des Jahres wird überprüft, ob die Schätzung richtig war. Wenn nicht, musst du etwas nachzahlen oder bekommst Geld zurück, je nachdem, wie viel du bezahlt hast.

![Musterrechnung](https://module-sachsen.dilewe.de/thumb/1e2e194824c669351ff8a2ee00fc40f1836d7992_100_musterrechnung.png)

# Aufgabe

![](https://module-sachsen.dilewe.de/media/8d4b9b6009f768c234170fde5db8061d9e5065aa_Physikalische-Gr%C3%B6%C3%9Fe-1.png)<!-- style="height: 80px" -->
Der Wasserkocher benötigt eine elektrische Energie $ E = 0,102\,\text{kWh} = 102\,\text{Wh} $. Eine Batterie benötigt die elektrische Energie $ E = 3,24\,\text{Wh} $.

Um herauszufinden, wie viele Batterien man dafür benötigen würde, muss man die elektrische Energie des Wasserkochers durch die elektrische Energie einer Batterie teilen.

> Somit ergibt sich:
>
> [[ 102 ]] $\text{Wh}$ : [[ 3,24 ]]  $\text{Wh}$/Batterie ≈ [[ 32 ]] Batterien
> Zusammen mit dem Preis für eine Batterie (ca. 0,50 €) ergeben sich hierbei Gesamtkosten von [[ 16 ]] €.
